# 架构决策记录（ADR）

本目录记录 GGFramework 跨仓库的**架构决策**：每条决策一个短文档，说明背景、决策、理由、被拒方案与影响。ADR 一旦接受即**不再修改正文**；若被取代，新增一条并把旧条目标记为"已被 ADR-XXXX 取代"。

## 索引

| 编号 | 标题 | 状态 |
|---|---|---|
| [0001](0001-core-独立仓库.md) | 将 GGFramework.Core 抽为独立仓库 | 已接受 |
| [0002](0002-vendoring-转-upm-迁移路线.md) | vendoring → UPM 单一源迁移路线 | 已接受（进行中） |

## 命名约定

- 文件名：`NNNN-简短标题.md`，编号四位、连续递增。
- 标题使用中文；文件名中的中文允许（与仓库既有中文提交风格一致）。

## 模板

新建 ADR 时复制以下结构：

```markdown
# ADR-NNNN: 标题

- 状态：提议 / 已接受 / 已废弃 / 已被 ADR-XXXX 取代
- 日期：YYYY-MM-DD
- 相关：ADR-XXXX、相关文件/仓库

## 背景

（面临的问题、约束、驱动力）

## 决策

（明确、可执行的一句话结论）

## 理由与取舍

（为什么这样选；权衡了什么）

## 被拒方案

（考虑过但未采纳的方案及原因）

## 影响

（正面/负面后果、后续动作、适用与失效条件）
```
